# 🤖 AI Customer Churn Intelligence

An End-to-End Machine Learning application that predicts telecom customer churn using customer demographics, service subscriptions, and billing information.

## 🚀 Features

- Customer Churn Prediction
- Interactive Streamlit Dashboard
- Risk Assessment
- Business Insights
- Retention Recommendations
- Downloadable Customer Reports

## 📊 Model Performance

| Model | Accuracy | ROC-AUC |
|---------|---------|---------|
| Logistic Regression | 80.70% | 84.16% |
| Random Forest | 78.64% | 82.51% |
| XGBoost | 78.50% | 82.14% |

### Selected Model

**Logistic Regression**

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-Learn
- SHAP
- Streamlit

## ⚙️ Run Locally

```bash
pip install -r requirements.txt

streamlit run app_v3.py
```
